Create a key at console.x.ai. Stored only in this browser and sent only to api.x.ai. In this mode local files can't be opened; PDFs are read from a screenshot.

    
    

      
      
    

    
    

    

  


  
Page access

  

  
Screenshots are sent for PDFs and pages with little readable text so the model can see the page number. For local files, turn on Allow access to file URLs in the extension's Details. If site access is limited, press Alt+Shift+G on a tab before asking.
